# F11b — ISO 50001 Screens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans`. Inline, one session, no subagents.

**Goal:** `/ekorm/iso-50001` on F11a's API (01 §7.17):
- the project home: progress bar, Gantt with statuses and the insufficient-dates message, per-clause summary, download of the ISO 50001 folder, update calendar;
- the calendar dialog;
- the checklist accordion: every sub-clause's full text, notes (add, list, edit, cancel, delete), evidence files (upload ≤ 30 MB, list, download, delete with confirmation) and its template;
- the TS EN ISO 50001:2018 guidance footer on every view.

**Architecture:**
- `features/iso50001/iso-page.tsx` holds the building gate and tabs `summary`/`checklist` (`?tab=`).
- Containers (`*-panel.tsx`) are split from pure views (stories + tests), as in F10b.
- The clause text comes from `GET /iso50001/clauses` in the request locale (Q-G2), so the screens hold no standard text.

**Spec:** 01 §7.17; 05 §13; F11a plan (R330–R341); 07 design system (MASTER, then OVERRIDES).

**Global Constraints:** as F10b (web gates, design rules, `SCREENS` line, message namespace `iso`, containers need tests only).
