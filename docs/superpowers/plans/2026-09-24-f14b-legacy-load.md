# F14b — Legacy Load, Comparison Tables, Remaining Collections, Artifacts

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans`. Inline, one session, no subagents.

**Goal:** Finish 08 §4–§6 on top of F14a:
- the remaining collections are transformed (tariffs, templates, SMTP, EPİAŞ, bill history, reports, logs, plants, alarms, carbon, ISO 50001);
- `ekokod migrate legacy load` writes a transform directory into Postgres, ordered, per stage transactional, re-runnable;
- `legacy_ids`, `legacy_bills`, `legacy_reports` exist (migration 00020);
- `ekokod migrate legacy artifacts` copies and registers files and reports orphans both ways.

`recompute`, `reconcile`, the runbook and `make migration-rehearsal` are F14c.

**Architecture:**
- Transform steps stay in `internal/migrate/legacy` (`transform_<area>.go`), same writer, same rejection ledger, same `input = accepted + rejected` check per collection.
- Operator answers for undeterminable facts go through **one** `--answers answers.csv` (`kind,legacy_id,answer`); each kind that is still unanswered is listed in `manual_<kind>.csv` (multipliers keep F14a's `manual_multipliers.csv` + `--confirmations`).
- The loader's SQL lives in `internal/store/postgres/admin/legacyload.go` (admin = the deliberate unscoped surface). It accepts only a **closed set of table names** (like `knownAggregateViews`); the orchestration (order, files, withheld readings, report) is `internal/migrate/legacy/load.go`.
- Tariffs are built as `model.Tariff` and checked with `domain/tariff.Validate` — the same rules the API enforces — before they are written.

**Spec:** 08 §4–§6, §11; 09 §F14; 04 (tables); legacy models `bcem-energy/src/utils/db/models/{Building,Tariff,TariffTemplate,Analyzer,Report,PowerPlant,Alarm,CarbonActivity,CarbonReports,EmissionFactors,EpiasHistory,Log,SMTPSettings}.ts`, legacy `app/api/iso/*` (collections `notes`, `files`, `projectDates`, keyed by `userId`).

## Rulings (R413–R429)

| Id | Rule |
|---|---|
| R413 | **Migration 00020_legacy.sql.** `legacy_ids(collection, legacy_id, table_name, new_id, pk(collection, legacy_id, table_name))` + index on `new_id`. `legacy_bills(id, company_id, building_id, analyzer_id null, scope 'building'\|'analyzer', period char(7) 'YYYY-MM', start_date, end_date, total_active_kwh, t1_kwh, t2_kwh, t3_kwh, inductive_kvarh, capacitive_kvarh, energy_cost, distribution_cost, capacity_cost, power_cost, green_energy_cost, reactive_penalty, reactive_penalty_applied, vat_cost, other_taxes_cost, total_cost, pdf_path, payload jsonb)`, unique `(scope, building_id, analyzer_id, period)` nulls not distinct. `legacy_reports(id, company_id, building_id, report_type, period, payload, pdf_path, excel_path, created_at)`. No tenant repository reads them yet (F14c reconcile reads through admin). |
| R414 | **Load mechanics.** Per table: the NDJSON lines are COPYed into a temp `stage(doc jsonb)` table, then `insert into T (cols) select cols from stage, jsonb_populate_record(null::T, doc) on conflict (<pk>) do update set <non-pk cols> = excluded.<col>` in one transaction. `cols` = the union of keys in the file, checked against `information_schema.columns` **before** any write — an unknown key fails the stage. Missing keys keep column defaults. The conflict target is the table's primary key read from `pg_index`. Table names come from a closed set; identifiers are quoted with `pgx.Identifier`. |
| R415 | **Load order** = 08 §6, restricted to tables with a file: integration_definitions → companies → company_weekend_days → company_vacations → calendar_events → users → user_password_history → buildings → building_contacts → analyzers → power_plants → power_plant_monthly_targets → power_plant_devices → power_plant_alarm_recipients → integration_credentials → smtp_settings → tariffs → tariff_taxes → tariff_manual_yekdem → tariff_templates → solar_tariffs → alarms → alarm_analyzers → alarm_channels → alarm_events → emission_factors → emission_factor_conversions → carbon_selected_activities → carbon_activities → carbon_reports → iso50001_projects → iso50001_clause_dates → iso50001_notes → market_prices_hourly → yekdem_monthly → operational_messages → meter_readings → plant_production_totals → consumption_anomalies → legacy_bills → legacy_reports → legacy_ids → stored_files. `meter_readings` and `plant_production_totals` go in chunks of 50 000 lines, each its own transaction (resumable: upserts). |
| R416 | **Load report.** `load_report.json`: per table `{lines, loaded, withheld}`; the invariant `lines = loaded + withheld` is asserted per table, and `loaded` is checked against the rows the insert reported. Load refuses a directory without `summary.json` (not a transform output). |
| R417 | **Tariffs.** Sources: `building.tariffs[]`, `building.tariff` when its `effectiveFrom` is not already in `tariffs[]`, standalone `tariffs` with a `building` and `energy_source != solar`. Key `(building, effective_from)`: the record with more non-null price fields wins, ties → embedded (what legacy billing read); the loser is rejected `duplicate_merged`. Classification per Q-J7. Enum maps: `residental/residential→residential`, `residentialPlus→residential_plus`, `commercialPlus→commercial_plus`, `martyrsFamilies→martyrs_families`, `publicLighting→public_lighting`, others same; `ag→lv`, `og→mv`; `attendant_company→incumbent`, `private_company→private`; `tl/usd/eur→TRY/USD/EUR`. `vat_rate` missing → rejected `vat_rate_missing`; PTF+YEKDEM without `energyKbk` → `kbk_energy_missing`; anything `tariff.Validate` refuses → `invalid_tariff` with its message. `allTaxes[]` (non-empty names) → `tariff_taxes`; else `other_taxes_rate > 0` → one line "Diğer vergi ve fonlar" (08 §5). `kbk.manualYekdem[]` → `tariff_manual_yekdem`. Legacy billing priced energy as `single_time_price || power_price` (`app/api/bill/route.ts` ~2086), so a single-time tariff without `single_time_price` takes `power_price` as its single-time price; `power_price` is never a power unit price (`power_unit_price` is). |
| R418 | **Templates.** `tarifftemplates` → `tariff_templates.payload` = `json(tariff.Input)` built by the same mapping (classification from `--answers tariff_template_class` or, absent, `lv/commercial/monomial/private` **flagged** in `manual_tariff_template_class.csv`; a template is only a starting point the user edits, so a default here cannot misbill). Duplicate `(company, lower(name))` → last by `_id` wins, loser rejected `duplicate_name`. |
| R419 | **SMTP.** `smtpsettings` → `smtp_settings` (one per company, last wins); `auth.pass` decrypted if `enc:` and re-sealed under `smtpPasswordAAD(company)` (exported as `postgres.SMTPPasswordAAD`). Empty `from` → rejected `required`. |
| R420 | **EPİAŞ.** `epiashistories` with `hour` → `market_prices_hourly(ts = Istanbul(date, hour) → UTC, ptf)`; the same `(date, hour)` twice → last wins, counted `duplicate_last_wins`. `yekdem` per `(year, month)` → `yekdem_monthly`, the value from the latest date; docs of that month that disagree are counted in the summary (`yekdem_conflicts`), not rejected. Docs without `hour` (daily averages) → rejected `daily_average_derived`. `epiasdailyaverages` is not read. |
| R421 | **Bill history.** `buildings.billHistory` and `analyzers.billHistory` → `legacy_bills` (scope building/analyzer). The key must be `YYYY-MM`, else rejected `bad_period`. Numbers through `num()`; `payload` = the whole legacy record as canonical JSON. Ids = `ID("legacy_bills", "<scope>:<hex>:<period>")`. |
| R422 | **Reports.** `reports` → `legacy_reports` (payload = monthlyReport/yearlyReport/carbonEmission/solarPlantSelection; pdf/excel paths kept for the artifact step). |
| R423 | **Logs.** `logs` → `operational_messages`: `type cron→job`, `alarm`, `system`; `company_id` resolved from `relatedModel`+`relatedId` (Analyzer → its company, Building → its company, Company → itself), else null; `related_type` lower-cased model, `related_id` = the migrated UUID when resolvable; `metadata` = legacy metadata + `legacy_id`; window per Q-J10. |
| R424 | **Plants.** `powerplants` → `power_plants` (orientation `kuzey/guney/dogu/bati/kd/gd/kb/gb → n/s/e/w/ne/se/nw/sw`; `plant_kind` = `rooftop` when the plant's name contains "çatı" (Turkish fold) — legacy reports split plants by exactly that name convention — else `grid`, listed in the summary for review); monthly targets (`ocak…aralik → 1…12`); inverters and `isolar_devices` → `power_plant_devices` merged by serial (`inverter_id` / `device_sn`); `isolar_alarm_email_recipients` → recipients (lower-cased, de-duplicated); `solarTariffs[]` + standalone solar tariffs (`energy_source = solar` or `powerPlant` set, `feed_in_tariff > 0`) → `solar_tariffs`; `santral_values` per Q-J12. An iSolar-linked plant gets `isolar_credential_id` = its company's ISOLAR credential, if any. |
| R425 | **Alarms.** Type map: `Reactive Limit Detection Alarm→reactive_limit`, `Data Communication Alarm→data_communication`, `Current - Voltage - Power Alarm→current_voltage_power`, `Invoice Alarm`/`Fatura Alarmı→invoice_increase`; unknown → rejected `unknown_type`. Company = the company of its analyzers (all must agree, else `company_ambiguous`; none → `company_unknown`). Unknown analyzers are dropped from the link and counted. `emailRecipients` → email channels; `smsNumbers` → sms channels (F7: visible but inactive). `logs[]` → `alarm_events` (message, triggered_at; `notified_at` null). `alarmTriggeredBillIds` per Q-J11. |
| R426 | **Carbon.** `carbonfootprints` docs (company, building, activities[]) → `carbon_activities`: main category from the Turkish name via the F10 catalogue; `scope`/`iso_category` recomputed from the sub-category (R301), never copied; status `Onay Bekliyor/Onaylandı/Reddedildi → pending/approved/rejected`; period from `date`/`endDate` (R401 parser); legacy `emissionCo2e` kept as `emission_kgco2e` (the F14c recompute recalculates). Unknown sub-category → rejected. `companyemissionfactors` → company-owned `emission_factors` + conversions. `carbonreporthistories` → `carbon_reports` (pdf path kept for artifacts). The legacy schema has no selected-activities list: `carbon_selected_activities` = the distinct activity types a building has used (so its data entry is not empty, Q-F5). |
| R427 | **ISO 50001.** Per Q-J9: `projectDates.dates` → `iso50001_clause_dates` (only clauses 5–9), `notes` → `iso50001_notes` (clause = `subItem`, unknown clause → rejected), `files` metadata → the artifact step (`owner_type iso50001`, `clause_id = itemNo`). |
| R428 | **Artifacts.** `ekokod migrate legacy artifacts --extract DIR --out TRANSFORM_DIR --source a,b,c --dest D`: the referenced files (bill `pdfPath`, report `pdfPath`/`excelPath`, carbon report pdf, ISO `files.path`) are resolved against the source roots, copied to `D/<company>/<owner_type>/<owner_id>/<sha256[:16]>-<base name>` (skipped when the same checksum is already there), and written to `stored_files.ndjson` in the transform dir (id = `ID("stored_files", <owner kind>:<ref>)`). `artifacts_report.json` lists referenced-but-missing and on-disk-but-unreferenced files; counts and total bytes feed reconcile (F14c). Paths that escape a source root are rejected `path_escape`. |
| R429 | **Fix from F14a.** The analyzer row lost `counterparty_no` (a comment swallowed it) and carried a non-column hint `multiplier_confirmed`; the column is written and the hint dropped (load reads `manual_multipliers.csv`, Q-J13). |
